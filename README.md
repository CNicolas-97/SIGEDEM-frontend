# SIGEDEM Frontend

Sistema Integral de Gestión Deportiva Municipal — interfaz de usuario.

## Tecnologías

- React 19
- Vite
- ESLint + Prettier

## Instalación

```bash
npm install
npm run dev
```

La app queda disponible en http://localhost:5173

## Ramas

- `main` — producción
- `develop` — desarrollo
